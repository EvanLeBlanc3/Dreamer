# Dreamer
Plays random clips from your own video folders, at random start times, with Classic TV, 3D, gamer and TV-guide transitions,
optional "Up Next" banners, TV-set frames, screen filters (CRT, VHS...), a subtle weather corner, Previous / Pause / Next controls
and 8 app color themes.
Install: upload every file here to a GitHub repo, turn on GitHub Pages (Settings > Pages > Deploy from branch > main / root),
open the Pages link in Chrome or Edge, and click Install. Works offline after the first load
(weather itself needs internet; offline it shows the last reading).
